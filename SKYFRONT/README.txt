SKYFRONT: Drone Defense

Запуск из этой папки:
    python main.py

В главном меню кнопка CHANGE DEVICE переключает режим управления:
- PC: клавиатура и мышь; WASD, Shift, Space, R, Q/E, V, ЛКМ.
- PHONE: экранные сенсорные кнопки движения, поворота камеры и действий.

Для мобильного режима запустите игру на устройстве с сенсорным экраном.
На ПК его можно предварительно проверить мышью.

Звуки находятся в assets/sounds. При запуске консоль выводит, какие WAV-файлы
удалось загрузить. Если звук не слышен, проверьте громкость Windows и устройства
вывода звука.

Зависимость: Panda3D 1.10.16 (pip install -r requirements.txt).
